Part 1, new file src/report.ts. Pure functions, no I/O:

```ts
/** Everything the report says, gathered by the route. Never an email, token or session text. */
export interface ReportInput {
  plugin: string;
  dsh: string | null;
  cli: string | null;
  binary: boolean;
  os: string;
  node: string;
  loggedIn: boolean;
  authMethod: string | null;
  configDir: string;
  stateDir: string;
  stateWritable: boolean;
  /** null when no session was named or no process is running for it. */
  mcp: { name: string; status: string }[] | null;
  lastError: string | null;
  switches: Record<string, boolean | number>;
  running: number;
}

/** The values that must never appear in the text. */
export interface PrivateValues {
  home: string;
  user: string;
  hostname: string;
  email?: string | null;
}

export function redact(text: string, p: PrivateValues, keepHost: boolean): string;
export function buildReport(input: ReportInput, p: PrivateValues, keepHost: boolean): string;
```

`redact` applies, in this order, each as a global replace:
1. `home` (when non-empty) to `~`; also the `file://` + home form.
2. every email (`/[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}/g`) to `<email>`.
3. `user` (when at least 3 characters) as a whole word (`\b` both sides, escape regex metacharacters) to `<user>`.
4. `hostname` (when non-empty and `keepHost` is false) as a whole word to `<host>`.
5. `/sk-ant-[A-Za-z0-9_-]{8,}/g` to `<token>` and `/Bearer\s+[A-Za-z0-9._-]{16,}/g` to `Bearer <token>`.

`buildReport` returns plain text, one `key: value` per line, in this order, then a blank line, then `Generated by dsh-oh-my-claude; edit before sending.`:

```
dsh-oh-my-claude <plugin>
dsh: <dsh or unknown>
Claude Code: <cli or "not found"> (<binary ? "on PATH" : "not on PATH">)
OS: <os>
Node: <node>
Login: <loggedIn ? "logged in" : "not logged in"><authMethod ? " · " + authMethod : "">
Config dir: <configDir>
State dir: <stateDir> (<stateWritable ? "writable" : "not writable">)
Host: <hostname>            <- only when keepHost, otherwise the line is omitted
Running sessions: <running>
MCP: <"n/a (no running session)" | "none" | "name=status, name=status">
Last error: <lastError or "none">
Switches: <"none" | "key=value, key=value" sorted by key>
```

The last statement of `buildReport` is `return redact(text, p, keepHost)`, so the whole text passes through redaction whatever a field held.
