# Contributing

Thanks for looking. The plugin is strict TypeScript with a lint contract that fails the build on the first miss, so read [docs/developing.md](docs/developing.md) before the first edit. It covers installing from a checkout, the rules, the gate (`bun run validate`) and the browser checks.

Contributions from AI coding agents are welcome on the same terms as anyone else's. Point the agent at that page too.

Found a bug? Open an issue at [github.com/lcestou/dsh-oh-my-claude/issues](https://github.com/lcestou/dsh-oh-my-claude/issues) with the dsh and Claude Code versions (`dsh --version`, `claude --version`) and what you expected to see. Settings → Oh My Claude → Report a problem writes that report for you.
